# tradinginfo

專做**台灣股票研究**的工作區,以**正確性**為最高優先。

📖 **報告目錄:<https://kbjiyu.github.io/tradinginfo/>**

## 用途

提供台股(延伸至相關美股／A股供應鏈)的資訊搜集、整理與分析,涵蓋:

- **股票市場分析**:大盤、資金面、外資動向、類股輪動
- **財報分析**:三大報表、獲利能力比率、月營收與季報趨勢
- **產業分析**:供應鏈上中下游、供需與競爭格局
- **前景分析**:成長動能、法人預估、風險因子
- **股價分析**:技術面、估值、支撐壓力
- **籌碼分析**:三大法人、融資券、大戶與集保分布

## 內容結構

- `index.html` — **報告目錄首頁**(GitHub Pages 進入點),可搜尋、篩選、排序
- `build_index.py` — 掃描資料夾並更新目錄清單的腳本
- `CLAUDE.md` — 工作區的分析原則、報告命名與目錄維護規範(Claude 的最高指導原則)
- `*.html` — 互動式研究報告

## 使用方式

在 Cowork 中直接提出研究需求(例如「分析台積電最新季報」「盤點 CoWoS 概念股籌碼」),
Claude 會依 `CLAUDE.md` 的原則搜集最新資料、產出結構化報告並存入本資料夾。

新報告產出後,執行以下指令同步目錄:

```bash
python build_index.py          # 更新 index.html 的報告清單
python build_index.py --check  # 只檢查是否有未同步的報告
```

命名規則與報告 `head` 需填的 `report-*` meta 詳見 `CLAUDE.md` 第八節。

> ⚠️ 本工作區所有內容為研究分析,非投資建議;資料有時效性,投資決策與風險由使用者自負。
