# tradinginfo

專做**台灣股票研究**的工作區，以**正確性**為最高優先。

## 用途

提供台股（延伸至相關美股／A股供應鏈）的資訊搜集、整理與分析，涵蓋：

- **股票市場分析**：大盤、資金面、外資動向、類股輪動
- **財報分析**：三大報表、獲利能力比率、月營收與季報趨勢
- **產業分析**：供應鏈上中下游、供需與競爭格局
- **前景分析**：成長動能、法人預估、風險因子
- **股價分析**：技術面、估值、支撐壓力
- **籌碼分析**：三大法人、融資券、大戶與集保分布

## 內容結構

- `CLAUDE.md` — 工作區的分析原則與工作流程（Claude 的最高指導原則）
- `*.html` — 互動式研究報告
  - `ai_server_supply_chain.html` — AI 伺服器供應鏈全鏈拆解（NVDA → 台股）
  - `tw_robot_supply_chain.html` — 台灣人形／自動化機器人供應鏈追蹤

## 使用方式

在 Cowork 中直接提出研究需求（例如「分析台積電最新季報」「盤點 CoWoS 概念股籌碼」），Claude 會依 `CLAUDE.md` 的原則搜集最新資料、產出結構化報告並存入本資料夾。

> ⚠️ 本工作區所有內容為研究分析，非投資建議；資料有時效性，投資決策與風險由使用者自負。
